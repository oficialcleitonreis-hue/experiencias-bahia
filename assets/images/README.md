# Fotos do projeto

As fotos enviadas na conversa estão descritas em `photo-map.json`, com número de referência, nome de arquivo sugerido e posição editorial planejada.

**Importante:** nesta integração, as imagens aparecem visualmente na conversa, mas seus arquivos binários não ficam acessíveis às ferramentas de escrita do GitHub. Portanto, ainda não foram gravadas no repositório e os espaços do site continuarão com marcadores até que os arquivos reais sejam anexados ao repositório. Não são usadas imagens genéricas ou substitutas.

Quando os arquivos estiverem disponíveis no repositório, use os nomes sugeridos em `photo-map.json` e atualize `assets/js/content.js` para apontar os espaços `images` e as imagens das experiências para ` /assets/images/nome-do-arquivo.jpg` (sem o espaço inicial). As fotos 1, 2 e 4 têm texto incorporado; escolha enquadramentos que preservem a legibilidade. Confirme também autorização de uso das pessoas retratadas e regras pertinentes às atividades mostradas.
